# 📊 Customer Data Analysis using Excel

## 📌 Overview
This project focuses on analyzing customer transaction data using advanced Microsoft Excel features. The goal is to extract meaningful insights, identify high-value customers, and perform data-driven decision making.

---

## 🎯 Objectives
- Analyze customer purchase behavior
- Identify top-performing customers
- Apply advanced Excel formulas and tools
- Perform data analysis and storytelling

---

## 🛠️ Tools & Technologies
- Microsoft Excel
- Data Analysis Toolpak

---

## 📂 Dataset Description
The dataset contains:
- Customer Name (repeated entries)
- Product purchases
- Individual item prices
- Transaction details

---

## 🔑 Key Features Implemented

### 1. Date & Time Functions
- `TODAY()` → Current date
- `NOW()` → Current date & time
- `DATEDIF()` → Difference between dates
- `EOMONTH()` → End of month calculations

---

### 2. Total Purchase Calculation
- Used formulas (SUMIFS / Pivot Table / Grouping)  
- Aggregated multiple entries per customer

---

### 3. Top 10 Customers Highlight
- Identified based on total purchase
- Applied **Conditional Formatting**
  - Top 10 rules
  - Highlighting using colors/icons

---

### 4. FILTER Function
- Extracted dynamic customer data
- Returned multiple matching records

---

### 5. Conditional Formatting (Advanced)
- Icons (↑ ↓ →)
- Data bars
- Color scales for quick insights

---

### 6. Timestamp Creation
- Used `NOW()` with iterative calculation
- Captures real-time updates

---

### 7. WHAT-IF Analysis
- Scenario Manager
- Goal Seek
- Used for forecasting and decision making

---

### 8. Linear Regression
- Performed using **Data Analysis Toolpak**
- Identified trends and relationships

---

### 9. High-Value Customer Identification
- Applied grouping logic
- Used formulas similar to **GroupBy concept**
- Segmented customers based on spending

---

### 10. Data Storytelling
- Converted raw data into insights:
  - Top customers
  - Purchase patterns
  - Revenue trends

---

## 📈 Key Insights
- A small percentage of customers contribute to a large portion of revenue
- Repeated customers have higher lifetime value
- Certain products drive most of the sales
