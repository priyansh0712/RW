# Inferential Statistics in Healthcare Data Analysis

## 📌 Project Overview

This project applies inferential statistical techniques on a healthcare dataset containing information about age, gender, lifestyle habits, and disease status. The purpose is to identify significant factors influencing diseases such as Diabetes and Hypertension using statistical hypothesis testing.

## 🎯 Objective

To analyze healthcare data and draw meaningful conclusions using inferential statistics techniques including confidence intervals, hypothesis testing, p-values, t-tests, chi-square tests, ANOVA, covariance, and correlation.

## 📊 Dataset Description

The dataset contains health records of individuals from different regions and includes attributes such as:

* Age
* Weight
* Gender
* Region
* Smoking Status
* Exercise Frequency
* BMI
* Blood Pressure
* Diabetes Status
* Hypertension Status
* Cholesterol Level
* Glucose Level

## 🛠 Tools & Libraries Used

* Python
* Pandas
* NumPy
* SciPy
* Statsmodels
* Matplotlib
* Seaborn
* Jupyter Notebook

## 📈 Analysis Performed

* Formulated statistical hypotheses
* Calculated confidence intervals
* Performed t-test
* Conducted chi-square test
* Performed ANOVA test
* Calculated covariance
* Calculated correlation
* Interpreted p-values and test results

## 📚 Conclusion

The project demonstrates how inferential statistics can be used to analyze healthcare data and determine relationships between lifestyle factors and disease occurrence. Statistical testing helps in making data-driven decisions and identifying significant health indicators.
