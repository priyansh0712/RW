# 📊 Spread Locator: A Statistical Distribution Analysis Model

## 📖 Project Overview

**Spread Locator** is a Python-based statistical analysis project designed to analyze customer transaction data using probability distributions and statistical techniques. The project evaluates transaction patterns, identifies the most suitable distribution for the data, and provides meaningful insights through statistical visualization and analysis.

---

# 📚 Part A: Statistical Concepts Covered

This part focuses on the theoretical concepts of probability distributions and statistical analysis used throughout the project.

### Probability Distributions

* Bernoulli Distribution
* Binomial Distribution
* Poisson Distribution
* Log-Normal Distribution
* Power Law Distribution

### Statistical Techniques

* Q-Q Plot Analysis
* Box-Cox Transformation
* Z-score Analysis

### Probability Visualization

* Probability Density Function (PDF)
* Cumulative Distribution Function (CDF)

## 📈 Key Findings

* Successfully analyzed customer transaction behavior using multiple statistical distributions.
* Identified Log-Normal Distribution as the best fit for transaction amounts.
* Improved data normality using Box-Cox Transformation.
* Detected outlier transactions through Z-score analysis.
* Visualized probability behavior using PDF, CDF, Histogram, and Q-Q Plot.
